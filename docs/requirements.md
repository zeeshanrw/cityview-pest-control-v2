## 2. Project Goals

1. Establish a professional, trustworthy online presence
2. Generate qualified leads via phone call / WhatsApp (primary conversion path — not a rigid quote form)
3. Rank locally on Google for pest control searches across confirmed GTA service areas
4. Build a foundation that scales with seasonal content (spring/summer pest surges)
5. **Quality bar: gold standard.** No rushed shortcuts — client has explicitly prioritized doing this right over doing this fast.

---

## 3. Scope of Work

### 3.1 Site Architecture

- **Homepage** — Hero section, services overview, trust signals, primary CTA
- **Service Pages (8–9 total, one per category):**
  - Termites
  - Bed Bugs
  - Rodents (mice/rats)
  - Ants
  - Cockroaches
  - Mosquitoes
  - Wasps/Hornets
  - Spiders
  - Wildlife Removal (raccoons, squirrels, etc.)
- **About Page** — Owner background, credentials, why-choose-us (solo operator = personal, direct service angle)
- **Service Area Page** — Confirmed cities/municipalities served, with local SEO targeting
- **Blog/Resources Section** — Seasonal pest guides (built for ongoing SEO content, not launch-blocking)
- **Contact Page** — Click-to-call + WhatsApp CTA primary; short fallback form secondary (name, city, pest type — no pricing fields)

### 3.2 Design Requirements

- Clean, minimalist layout — no visual clutter
- Mobile-first (majority of pest control searches happen on phone, high-urgency context)
- Built around client's existing logo and brand assets
- Real photos of the owner (van, uniform, job sites) — **client to provide** via phone camera
- Licensed stock photography (Unsplash/Shutterstock) permitted **only** for generic pest identification images where client has no real photo
- **Prohibited:** No images/video sourced from competitor or third-party pest control websites (copyright risk)

### 3.3 Conversion Strategy

- **Primary CTA across all pages:** "Call or WhatsApp for a Free Quote" — reflects negotiated, non-fixed pricing model
- Click-to-call button fixed/prominent in header (mobile especially)
- WhatsApp click-to-chat integration
- Secondary contact form kept short: 3–4 fields max (name, city, pest type, contact method) — no pricing/quote fields, since pricing isn't fixed
- No pricing tables or fixed-rate listings anywhere on site (avoid setting false pricing expectations)

### 3.4 Technical Stack

- **Framework:** Next.js
- **Styling:** Tailwind CSS
- **Hosting:** TBD (Vercel recommended for Next.js compatibility)
- **Performance targets:** Core Web Vitals compliant — LCP < 2.5s, mobile-optimized

### 3.5 SEO Strategy

- **Local SEO focus** over broad/national ranking
- Google Business Profile setup and optimization
- Schema markup: Local Business + Service schema per pest-type page
- Confirmed service area targeting (currently: Mississauga, Brampton; York Region cities pending confirmation)
- On-page SEO: title tags, meta descriptions, header structure per service page
- Seasonal content calendar (spring termite/ant season, summer mosquito/wasp season, fall rodent/wildlife entry season)
- Local citation building (GTA business directories) — post-launch phase
- Review generation strategy (Google reviews) — post-launch phase
